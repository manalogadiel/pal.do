# Study Tab Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a Study tab with a timestamp-based 25/5 Pomodoro (long break after every 4th round), phase alarms, and a daily focus total.

**Architecture:**
- Pure timer logic in `src/lib/session.ts`, unit-tested through the existing eval runner.
- Session state lives in `App` (not the tab), so switching tabs never stops the timer. It persists in the `paldo-v1` save.
- `src/components/Study.tsx` is presentational.
- Alarms: Android `LocalNotifications` with a reserved id; web Notification API plus a WebAudio chime.

**Tech Stack:** React 19, TypeScript 5.7, Tailwind v4, Capacitor 8 `@capacitor/local-notifications`, Vite 8 (`ssrLoadModule` for tests).

**Spec:** `docs/superpowers/specs/2026-10-10-study-tab-design.md`

## Global Constraints
- Timer values: `FOCUS = 25 min`, `BREAK = 5 min`, `LONG_BREAK = 15 min`, `LONG_EVERY = 4`.
- The timer is timestamp-driven. Correctness never depends on `setInterval` firing.
- Reserved native notification id: `SESSION_ALARM_ID = 900001`. Calendar alarm ids must stay `< 900000`.
- No streaks, leaderboards, or comments on the student's state. The focus total is a neutral number: "Today: N min focused".
- Quiet hours (`isQuiet`, 11pm–7am) mute the chime only. Visual changes still happen.
- Must work at 375px width and in dark mode, using existing tokens (`liquid`, `press`, `tnum`, tangerine).
- Strings with apostrophes use double quotes (AGENTS.md). Components use a named export (matching how `App.tsx` imports `Today`/`Tasks`) **and** a default export (AGENTS.md), like `StatusBadge.tsx`.
- There's no test framework: tests are `*.test-cases.ts` modules returning failure lists, run by `pnpm eval:chat`.

## Review Focus
1. **Reload mid-round** → the countdown resumes with the correct remaining time. Covered by the persistence wiring in Task 4 plus the Playwright step in Task 5.
2. **App closed through several phases** (phone slept 2h) → it lands in the correct phase and round, and the focus minutes are logged. Covered by the `jump` test in Task 1.
3. **Switching tabs while running** → the timer keeps running and the tab dot shows. Covered by state living in App (Task 4) and the Playwright step in Task 5.
4. **Calendar change during a session** → the session alarm survives. Covered by the `eventAlarmId` range test (Task 2) plus `syncEventAlarms` skipping `SESSION_ALARM_ID`.
5. **Pause, then reload** → it stays paused with the same remaining time, and doesn't silently run. Covered by the `paused tick is frozen` test (Task 1) plus the Task 5 Playwright step.

### Task 1: Timer model (`session.ts`) + tests wired into the eval runner

**Files:**
- Create: `src/lib/session.ts`
- Create: `src/lib/session.test-cases.ts`
- Modify: `scripts/eval-chat.mjs`

**Interfaces:**
- Produces:
  - `type Phase = 'idle' | 'focus' | 'break'`
  - `interface Session { phase: Phase; round: number; phaseEndsAt: number; pausedLeft?: number; completedFocusMs: number }`
  - `const FOCUS_MS = 1_500_000`, `BREAK_MS = 300_000`, `LONG_BREAK_MS = 900_000`, `LONG_EVERY = 4`
  - `const IDLE: Session = { phase: 'idle', round: 1, phaseEndsAt: 0, completedFocusMs: 0 }`
  - `start(now: number): Session`
  - `pause(s: Session, now: number): Session`
  - `resume(s: Session, now: number): Session`
  - `skip(s: Session, now: number): Session`
  - `stop(): Session`
  - `tick(s: Session, now: number): Session`
  - `remaining(s: Session, now: number): number` (ms)
  - `phaseLabel(s: Session): 'Focus' | 'Break' | 'Long break' | ''`
  - `isPaused(s: Session): boolean`
  - In the test file: `runSessionTests(): string[]` (empty = all pass)

Rules the tests pin:
- `round` is 1–4.
- A break after round 4 is a long break. When a long break ends, `round` resets to 1. Otherwise the next focus is `round + 1`.
- Natural phase ends chain from the previous `phaseEndsAt` (not `now`), so long jumps land exactly.
- `skip` starts the next phase at `now` and credits only elapsed focus time. Skipping a break credits nothing.
- `pause`/`skip`/`tick` on `idle` return the input unchanged. `tick` on a paused session returns it unchanged.
- `completedFocusMs` only grows within a session. `stop()` resets to `IDLE`.

- [ ] **Step 1: Write the failing tests** in `src/lib/session.test-cases.ts`.

```ts
import { FOCUS_MS, IDLE, pause, phaseLabel, remaining, resume, skip, start, stop, tick } from './session'

const MIN = 60_000
export function runSessionTests(): string[] {
  const fails: string[] = []
  const eq = (name: string, got: unknown, want: unknown) => { if (JSON.stringify(got) !== JSON.stringify(want)) fails.push(`${name}: got ${JSON.stringify(got)} want ${JSON.stringify(want)}`) }
  const pick = (s: ReturnType<typeof start>) => ({ phase: s.phase, round: s.round, phaseEndsAt: s.phaseEndsAt, completedFocusMs: s.completedFocusMs })

  const s0 = start(0)
  eq('start', pick(s0), { phase: 'focus', round: 1, phaseEndsAt: 25 * MIN, completedFocusMs: 0 })
  eq('start remaining', remaining(s0, 0), FOCUS_MS)
  eq('focus→break', pick(tick(s0, 25 * MIN)), { phase: 'break', round: 1, phaseEndsAt: 30 * MIN, completedFocusMs: 25 * MIN })
  eq('break→focus r2', pick(tick(s0, 30 * MIN)), { phase: 'focus', round: 2, phaseEndsAt: 55 * MIN, completedFocusMs: 25 * MIN })
  // r4 focus 90–115, long break 115–130
  const r4 = tick(s0, 116 * MIN)
  eq('long break', [r4.phase, r4.round, phaseLabel(r4), r4.phaseEndsAt], ['break', 4, 'Long break', 130 * MIN])
  eq('after long break', pick(tick(s0, 130 * MIN)), { phase: 'focus', round: 1, phaseEndsAt: 155 * MIN, completedFocusMs: 100 * MIN })
  eq('jump 2h', pick(tick(s0, 120 * MIN)), { phase: 'break', round: 4, phaseEndsAt: 130 * MIN, completedFocusMs: 100 * MIN })

  const p = pause(s0, 10 * MIN)
  eq('pause left', p.pausedLeft, 15 * MIN)
  eq('paused tick is frozen', tick(p, 999 * MIN), p)
  eq('paused remaining', remaining(p, 999 * MIN), 15 * MIN)
  const r = resume(p, 60 * MIN)
  eq('resume', [r.phaseEndsAt, r.pausedLeft], [75 * MIN, undefined])

  eq('skip focus credits elapsed', pick(skip(s0, 10 * MIN)), { phase: 'break', round: 1, phaseEndsAt: 15 * MIN, completedFocusMs: 10 * MIN })
  const b = tick(s0, 26 * MIN)
  eq('skip break', pick(skip(b, 27 * MIN)), { phase: 'focus', round: 2, phaseEndsAt: 52 * MIN, completedFocusMs: 25 * MIN })
  eq('skip paused focus', pick(skip(pause(s0, 5 * MIN), 40 * MIN)), { phase: 'break', round: 1, phaseEndsAt: 45 * MIN, completedFocusMs: 5 * MIN })
  eq('idle tick', tick(IDLE, 5 * MIN), IDLE)
  eq('stop', stop(), IDLE)
  return fails
}
```

- Produces: `Study` component with props
  `{ session: Session; pal: PalId; palState: PalState; todayMinutes: number; alarmsOn: boolean; onStart(): void; onPause(): void; onResume(): void; onSkip(): void; onStop(): void; onEnableAlarms(): void }`

Behaviour decided here:
- **Saved / load:**
  - `Saved` gains `session?: Session` and `focusLog?: Record<string, number>`, keyed by `new Date().toDateString()`, in minutes.
  - `load()` defaults them to `IDLE` and `{}`.
  - App state is initialised as `tick(init.session ?? IDLE, Date.now())`. Both are added to the persistence effect's object and deps.
- **One reconciler** `applySession(next: Session, prev: Session)` in App:
  - **Log:** `delta = next.completedFocusMs - prev.completedFocusMs`. If `delta > 0`, add `Math.round(delta / 60000)` minutes to `focusLog[today]`.
  - **Phase change:** if `next.phase !== prev.phase || next.round !== prev.round` and `next.phase !== 'idle'`:
    - call `scheduleSessionAlarm(next.phaseEndsAt, title, body)` (the title is the pal's name, the body is the line below);
    - `notifyWeb(...)` when `document.hidden`;
    - `playChime()` unless `isQuiet(Date.now())`;
    - `setBubble({ id: uid(), mascotId: pal, text: say(pal, key), kind: 'response' })`, where the key is `breakStart` / `longBreak` / `focusStart`;
    - `feel('cheer', 1500)` when a focus round just completed.
  - `setSession(next)`.
- **Handlers:**
  - `onStart` → `applySession(start(Date.now()), session)`.
  - `onPause` → `cancelSessionAlarm()`, then apply `pause`.
  - `onResume` → apply `resume`, then `scheduleSessionAlarm(resumed.phaseEndsAt, …)`. This is an explicit call because the phase doesn't change.
  - `onSkip` → apply `skip`.
  - `onStop` → `cancelSessionAlarm()`, then `setBubble` with `say(pal, 'sessionDone', { m: todayMinutes })`, then `setSession(stop())`.
- **Reconcile loop:** `useEffect` with `setInterval(…, 1000)` while `session.phase !== 'idle' && !isPaused(session)`. It calls `applySession(tick(session, Date.now()), session)` only when `tick` returns a different phase or round. A `visibilitychange` listener runs the same reconcile on return to the tab.
- **Study's own display clock:** inside `Study`, a `useState(Date.now())` refreshed every 1000ms while running, for display only.
- **Render:** `view === 'study'` renders `<Study …/>` (before the `tasks` branch). `studying={session.phase !== 'idle'}` is passed to both `Rail` and `TabBar`.
- **Pal state for Study:** `mood ? mood.state : session.phase === 'break' ? 'happy' : 'idle'`.
- **`alarmsOn` / `onEnableAlarms`:**
  - `alarmsOn` is `settings.notify`.
  - `onEnableAlarms` reuses `requestNotificationPermission()` and sets `settings.notify` like the existing notify card handler (App ~:640).
  - The Study UI shows a one-line "Turn on alarms so you hear when a round ends" button only when `!alarmsOn`.
- **Copy** in `BASE`:
  - `focusStart: ["Focus time! I'll stay right here.", "Okay, 25 minutes. You've got this."]`
  - `breakStart: ['Nice round! Take 5, stretch and drink water.', 'Break time. Look away from the screen for a bit.']`
  - `longBreak: ['Four rounds done! Take a longer 15-minute break.']`
  - `sessionDone: ['Session saved. {m} min focused today.']`

  2. Countdown `mm:ss` in `tnum text-[64px] font-semibold`, from `remaining(session, displayNow)`. Idle shows `25:00`.
